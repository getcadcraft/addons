---
title: Place numbered notes
summary: Put numbered note bubbles on a drawing and edit them in the Properties panel.
section: tasks
order: 10
keywords: note, bubble, number
---

Type {{cmd:NOTE}} (or click {{ui:Note}} in the Notes group), click where the bubble goes, then type the note's text.
Each note gets the next free number.

Drag the text's grip to move the text; the leader follows. Select a note to change its number or text in the
Properties panel.

:::tip
A drawing with notes opens in any CAD program as ordinary block references. The note data travels with them.
:::
